India Job Market & Recruitment Trends Dashboard

Project Overview

This is a personal data analytics project developed using Microsoft Power BI. It analyses a public LinkedIn job-posting dataset to explore job market trends in India.

Project Objectives

- Analyse job postings across different states and industries.
- Identify the top 10 companies by job postings.
- Explore job postings by experience level and company size.
- Analyse work types and employment types.
- Understand application trends across job sectors.

Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query

Key Performance Indicators (KPIs)

- Total Job Postings
- Total Companies
- Total Applications
- Average Applications per Job

Dashboard Features

- Interactive State, Industry and Job Level slicers.
- Job postings by state, industry and sector.
- Top 10 companies by job postings.
- Analysis by experience level, work type, employment type and company size.
- Applications by job sector.

Dataset

Public LinkedIn job-posting dataset.

Source: "LinkedIn Dataset Analysis" (https://github.com/Shreyashgol/linkedIn-dataset-analysis)

Project Files

- Power BI Dashboard (.pbix)
- Project Report (.pdf)
- Dashboard Screenshot (.png)

Key Learning

This project helped me practise DAX measures, Power BI visualisation, KPI reporting and interactive dashboard development.

Note

This project analyses public job-posting data. It does not represent internal company recruitment records or actual hiring outcomes.
