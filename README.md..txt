India Job Market & Recruitment Trends Dashboard

Project Overview

This is a personal data analytics project developed using Microsoft Power BI. It explores a public LinkedIn job-posting dataset to understand job market trends in India.

Objectives

- Analyse job postings across different states and industries.
- Identify the top 10 companies by job postings.
- Explore job postings by experience level and company size.
- Analyse work types and employment types.
- Understand application trends across job sectors.

Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query

Key Performance Indicators

- Total Job Postings
- Total Companies
- Total Applications
- Average Applications per Job

Dashboard Features

- Interactive State, Industry and Job Level slicers.
- Job postings by state, industry and sector.
- Top 10 companies by job postings.
- Analysis by experience level, work type, employment type and company size.
- Applications by job sector.

Dataset Source

Public LinkedIn job-posting dataset:
